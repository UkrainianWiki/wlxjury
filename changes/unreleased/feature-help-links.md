section: Features

- Help links: the admins' and organizers' pages link the section of the user guide that explains them ("More about the file score", "More about the statistics", …), and the jurors' gallery has a Help link to the jurors' guide. The links open the English guide on GitHub as it was at the running version, in a new tab. The guide gains sections on criteria, the local image cache, the round image check, the changes to a round and the top files.
